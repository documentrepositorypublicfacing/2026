OVERVIEW

How ATOT Access Works

The ability to use the Alabama Teacher Observation Tool (ATOT) in Cognia’s Continuous Improvement Site (myjourney.cognia.org) involves multiple steps of approval and verification in ALSDE’s AIM and the Teaching Effectiveness (TE) Platform. Access to ATOT must be managed within the Teacher Observation Tool Module in Cognia.

There are two parallel systems that must both be configured correctly:

  • ALSDE AIM / ATGP — Controls which users are verified as Observers or Instructors. Managed at aim.alsde.edu.
  • Cognia myJourney / ATOT — Controls access to the Teacher Observation Tool dashboard. Managed at myjourney.cognia.org.
Key rule: Users are loaded from ALSDE to Cognia via a nightly roster file. All information must be correct and verified in AIM/ATGP before the next business day for access to take effect in Cognia.
PART 1

ALSDE AIM & ATGP Setup

  1. 1

    Districts must ensure all information and roles in the Education Directory (EdDir) are accurate. A local Education Directory Application Editor can assist with assigning access rules.

    • Evaluators/Observers (school level) — must be assigned the Teaching Effectiveness (TE) App School Certifier role. This allows the administrator to certify all school data.
    • Reviewers/Observers (central office level) — must be assigned the Teaching Effectiveness (TE) App System Certifier role. This allows central office staff to certify all system data.
  2. 2

    The user must log into the AIM portal (aim.alsde.edu). When all information in the Education Directory is correct, the user should see the ATGP tile (labeled “Teaching Effectiveness”).

    Note: All data is generated directly from the Education Directory to the AIM portal. If the tile is not visible and Education Directory information is accurate, contact the ALSDE Service Desk at 334-694-4777 or servicedesk@alsde.edu.
  3. 3

    School administrators must log into AIM, select the Teaching Effectiveness tile, then go to Roster Management and click Get Roster. Select the Edit link for each user, change their status to “Verified”, and save. Then submit the roster.

    Note: If a teacher/instructor needs to be removed, they must be deleted from both the Position tab and the Application tab. For help, contact Alabama Supercomputer at 1-800-338-8320 or 256-971-7448 — teachingeffectiveness@asc.edu.
  4. 4

    Allow 24–48 hours for information in the AIM portal to transfer to Cognia’s myJourney and vice versa. If information does not match, an error message will appear.

    For additional assistance, contact Cognia Client Care at alsde.onlinehelp.cognia.org or 1-888-413-3669.

For implementation questions, email ATGP@alsde.edu.

PART 2

Accessing ATOT in myJourney

The Teacher Observation Tool is accessed from the myJourney dashboard for the district or school (myjourney.cognia.org).

  1. 1

    On the myJourney dashboard, select the first icon (Observations) to open the Observations modules popup.

  2. 2

    In the Observations popup, the Teacher Observations widget is displayed alongside the eleot Observations widget. Select Go to Teacher Observations in the Teacher Observations widget.

    The Teacher Observation Tool opens in a new browser tab.

    If you see “Request Access to Teacher Observations” instead: The institution has access but you have not been added as a user. Click the button to send an email access request to the Head of Institution and Primary Contact on file with Cognia.
    If you see only “Learn more about Teacher Observations”: The institution does not yet have access to the Teacher Observation Tool.
PART 3

User Roles in Cognia ATOT

Five roles are available within the Teacher Observation Tool. An Admin can assign multiple roles to a user. Cognia receives an approved user roster from ALSDE nightly — users verified in AIM/ATGP will be available in Cognia the next business day.

Role Platform Where Managed Permissions
Admin (HOI) Cognia myJourney
myjourney.cognia.org		 Create observations (if verified observer), view all observations, archive/restore observations, generate reports for all observations, and manage users.
Admin (non-HOI) Cognia myJourney
myjourney.cognia.org		 Create observations (if verified observer), view observations, archive/restore observations, generate reports for their own observations only, and manage users.
Observer Verified in ATGP (aim.alsde.edu) + matched in ATOT module in Cognia Create and edit their own observations (if verified observer).
Instructor Verified in ATGP (aim.alsde.edu) + matched in ATOT module in Cognia Does not have access to the Teacher Observation Module (unless also assigned another role). Available as an option in the instructor field for new observations and as a filter in reports.
Report Viewer Granted in User Management inside the ATOT module (myjourney.cognia.org) Generate reports for all observations. Only available once the user has also been assigned the Observer or Admin role.
No Access error: If you are not rostered as an approved observer, a “No Access” popup will display when you try to create an observation. Contact your administrator.
Invalid Instructor error: If the instructor has not been rostered as an approved instructor, an “Invalid Instructor” popup will display. The instructor must be verified in AIM/ATGP.
PART 4

Am I in ALSDE Identity Management (AIM) Correctly?

  1. 1

    If a user cannot create or be involved in an observation in ATGP, they need to ensure the correct application access rules are assigned by the Education Directory editor in AIM (aim.alsde.edu).

    Contact ALSDE Service Desk: 334-694-4777 or servicedesk@alsde.edu.

  2. 2

    AIM (aim.alsde.edu) is the starting point for all ALSDE applications. Access is managed through the Education Directory (EdDir) application.

    Teachers cannot access EdDir directly. They need their local Education Directory Application Editor to assign application access rules after the AIM account is fully created (SSN/DOB entered and ALSDE ID assigned). Editors are typically superintendents or principals, as determined by each LEA.
PART 5

Am I Verified in ATGP Correctly?

A user must be a verified ATGP user to participate as an Observer and/or Instructor in ATGP on the Cognia platform. The following application access rules must be assigned in the Education Directory:

  • Teachers/Instructors — TE App School Editor at the school level. Can edit school data.
  • Evaluators/Observers (school level) — TE App School Certifier at the school level. Can certify all school data.
  • Reviewers/Observers (central office) — TE App System Certifier at the system level. Can certify all system data.

Before Cognia receives user information, it must be verified by an authorized user (typically the principal at the school or a designated person at the central office).

The fields school/district name, role, email address (must match the email used in Cognia), first name, and last name must match exactly between AIM and Cognia ATOT for the user to create or be involved in observations.

Roster Management in ATGP

An authorized principal or other user can view and edit the roster on the Roster Management page in ATGP:

  • A
    Get Roster — Load/refresh the roster for the specified system and school.
  • B
    Verify Roster — Affirm that the roster is ready for submission.
  • C
    Submit Roster — Mark all verified entries as ready to send to Cognia.
Submitted roster entries are sent to Cognia nightly. An authorized user may resubmit an updated roster at any time.
