The System

Two tools. One workflow. Obsidian holds the knowledge. Claude does the work.

8 MIN

Obsidian + Claude: How They Fit

The System

Obsidian — the knowledge layer

  • Local Markdown files on your computer
  • Organized vault of notes, summaries, references
  • Nothing goes to the cloud unless you choose

Claude — the AI layer

  • You paste in the context it needs from Obsidian
  • It reads, synthesizes, and builds from what you give it
  • Outputs go back into the vault
Obsidian vault — the knowledge layer

Feeding the Machine

  • Email summaries (via Copilot → Keep → Obsidian)

Reads the context you share, connects it to what you're asking, and builds from it — so each session starts where the last one ended.

Publishing

GitHub Pages. No web team, no CMS, no hosting bill.

5 MIN

One File. One Upload. Public URL.

Publishing

The workflow

  • Claude builds the HTML file
  • Upload to a GitHub repository
  • GitHub Pages publishes it instantly
  • Add a short link (Rebrandly, bit.ly) for sharing

What you get

  • A permanent, shareable URL
  • Free hosting, no maintenance
  • Update the file → URL stays the same

06

Data Privacy by Design

FERPA compliance isn't a disclaimer at the end. It's a design principle from the start.

5 MIN

What Goes In — What Never Does

Data Privacy

✓ Safe to use with Claude

  • Meeting notes (no student data)
  • Publicly available information
  • Your own professional documents
  • Structural and formatting tasks
  • Research and reference work

✗ Keep off the AI layer

  • Student names, IDs, grades, records
  • Staff evaluations or personnel data
  • Anything under a FERPA, HIPAA, or confidentiality obligation
  • Internal legal or HR communications
