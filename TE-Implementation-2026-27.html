2026–2027 District Options

Do this first: the superintendent or designee must select one of the three options below in the AIM Portal before any other step on the calendar — self-assessments, PLPs, evidence, or ATOT observations — can be completed.
  1. 1 Teachers self-assess on all ten Alabama Core Teaching Standards. All classroom teachers are observed using the Alabama Teacher Observation Tool (ATOT). District leaders self-assess on all LEADAlabama indicators. School administrators complete the APLDS Evaluation System.
  2. 2 Teachers self-assess on specific Alabama Core Teaching Standards determined by the district. All classroom teachers are observed using the ATOT. District leaders self-assess on the LEADAlabama indicators determined by the district. School administrators complete the APLDS Evaluation System.
  3. 3 All classroom teachers are observed using the ATOT. School administrators complete the APLDS Evaluation System. Teachers and district leaders use the LEA-developed and/or adopted evaluation system. The LEA is responsible for storing and maintaining all evaluation system data.

Getting Set Up in ATOT

All information must be correct in the Education Directory (EdDir) and in the ATOT before observations begin.

  1. 1 Confirm EdDir access rules are assigned correctly: school-level observers need TE App School Certifier; central-office reviewers/observers need TE App System Certifier.
  2. 2 Log in to the AIM Portal. The TE tile is generated directly from EdDir — if it isn’t visible, EdDir information is inaccurate and the LEA EdDir Editor needs to update it.
  3. 3 School administrators use the TE tile / roster management in AIM to verify instructors are assigned to the correct site and access rules.
  4. 4 Allow 24–48 hours for AIM Portal changes to sync to ATOT (and vice versa). The e-mail on file in ATOT must match AIM exactly.
  5. 5 Confirm the teacher is listed in myJourney before conducting observations; add via Manage Users using the same name/e-mail as EdDir if missing.
