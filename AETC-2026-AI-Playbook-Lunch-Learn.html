EOD & Calendar Handoffs

Closing the Loop

End-of-Day routine

  • One command triggers a dated session log from a standing template
  • Claude surfaces candidate action items & calendar events for me to confirm — nothing gets added unreviewed
  • Standing context file gets updated if anything changed

Calendar handoff format

  • Confirmed items come out as clean, structured blocks — one event or task per block
  • Built for pasting straight into Gemini/Copilot, since neither product plugs directly into my vault
  • One block at a time avoids keyword collisions where the assistant grabs the wrong task

Copy · fill in the bracket · paste into your AI of choice

Here's a workflow I saw demonstrated today:

Obsidian (free, local note-taking app) serves as a personal knowledge vault — meeting notes, email summaries, role context, and reference documents. An AI assistant (Claude, ChatGPT, Gemini) with access to that vault drafts documents, builds public-facing resources, and carries context forward across sessions — no more starting from zero each time. Outputs are built as single HTML files, published to GitHub Pages, and shared via short links — no web team, no CMS, no cost.

As the vault grows, the workflow grows with it. The documents you can build and publish will change as your knowledge base does — what starts as a simple reference page can evolve into something more connected and complex over time.

The full presentation is at drjmc.link/AIplaybook if you'd like a frame of reference for what was demonstrated — what this looks like in practice may be different from what you'd expect or recommend.
