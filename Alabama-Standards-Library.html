Core standards and frameworks for Alabama educators and school leaders

About This Library This page collects the foundational Alabama State Department of Education standards that underlie teacher and leader evaluation and professional learning — the Core Teaching Standards, the Standards for School Leadership, the Standards for Professional Learning, and the Educator Code of Ethics. Each links to its own page with the full standards text, nicely formatted for reading online. All documents are publicly available and may be freely shared.

Alabama Standards & Frameworks

Alabama Core Teaching Standards (ACTS)
Ala. Admin. Code r. 290-3-3-.03 — the foundational standards defining effective teaching practice in Alabama, and the basis for Alabama Teacher Growth Program (ATGP) evaluation indicators.
https://bit.ly/AL-TeachingStandards
Alabama Standards for School Leadership
Ala. Admin. Code r. 290-4-3-.04 (updated September 2024) — the 5 Domains of Principal Effectiveness that form the basis for APLDS evaluation indicators.
https://bit.ly/ALSchoolLeadStandards
Alabama Standards for Professional Learning
Updated December 2024 — defines what constitutes high-quality, ALSDE-approved professional learning for Alabama educators. Full version and 1-pager.
https://bit.ly/AL-PLstandards
Alabama Educator Code of Ethics
The ALSDE Code of Ethics governing the conduct expected of all certified Alabama educators.
https://bit.ly/AL-EdEthics
