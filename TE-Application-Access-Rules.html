Teaching Effectiveness Application Access Rules

Alabama State Department of Education — Education Directory

Permalink: https://bit.ly/aleddev-eddir

To access the Teaching Effectiveness application, users will need to be assigned a Teaching Effectiveness application access rule in the Education Directory. Users will also need to be assigned to a System and Site in the Education Directory. Instructions for assigning and removing access rules in the Education Directory are provided below.
School Editor

Teaching Effectiveness App School Editor

Assigned to: Teachers, Counselors, Media Specialists/Librarians

Users assigned this access rule will be able to perform their annual evaluation using the Educate annual evaluation process.

School Certifier

Teaching Effectiveness App School Certifier

Assigned to: Principals & Assistant Principals

Users assigned this access rule will be able to perform their annual evaluation using the APLDS annual evaluation process. They will also be able to perform administrative tasks for their site in the application.

System Editor

Teaching Effectiveness App System Editor

Assigned to: Central Office Evaluatees

Users assigned this access rule will be able to perform their annual evaluation using the LEAD annual evaluation process.

System Certifier

Teaching Effectiveness App System Certifier

Assigned to: Superintendents & Assistant Superintendents

Users assigned this access rule will be able to perform administrative tasks at any site in their district in the application.

Please note: Users should only be assigned one Teaching Effectiveness application access rule. Assigning a user multiple Teaching Effectiveness application access rules can cause conflicts in the application.
ASSIGN ACCESS

How to Assign a Teaching Effectiveness Access Rule

Access rules are assigned to users in the Education Directory by the LEA's Education Directory Application Editor. Follow these steps to assign a Teaching Effectiveness access rule to a user.

  1. 1

    Log into AIM. The Education Directory Application Editor must log into AIM (aim.alsde.edu) and select the Education Directory tile.

  2. 2

    Prepare to find the user. Go to the staffing screen.

    • a

      Select the school.

    • b

      Select Application Access.

    • c

      Select Add Staff.

  3. 3

    Search for the user. Provide details about the user. ALSDE ID is preferred.

    Careful: Watch for nicknames — for example, if a name is listed as "Rob" and you search "Robert," you will not find the user.

    Select Search to continue.

  4. 4

    Select the correct user.

    • a

      Verify SSN.

    • b

      Verify ALSDE ID.

    • c

      Verify DOB.

    • d

      Select Use Person to assign an application access rule to this user.

    Note: Select Refine Search to return to the search screen and search again.

  5. 5

    Assign the application access rule. Confirm the school.

    • a

      Filter app access rules to only rules containing "teach."

    • b

      Select the desired rule(s) for the user.

    • c

      Select Add app access rule to add the rule(s) to the user.

    Select Pick another person to return to the selection screen.

  6. 6

    Confirm the user has access.

    • a

      Filter the application access rules grid to show only the Teaching Effectiveness application.

    • b

      Further filter by partial name or email address.

  7. 7

    Add a position. The user must also be assigned to at least one position. Select the Positions tab and follow the same procedure to add the user to a position.

    More efficient option: Select View on the user's row, then select Add position… to add a position to the selected user.
Configuration complete once the user can log into AIM and see the Teaching Effectiveness (TE) tile. The user will also appear in the roster for the specified school.
REMOVE ACCESS

How to Remove a User's Access

  1. 1

    View existing positions and rules. Select View to see all positions and application access rules assigned to a user. Select Remove to remove a single position or rule.

    More efficient option: Use Remove All… to remove all positions and/or app access rules at once (from your school or system).

    Note: If you are a school editor and the user has staff assignments at another school, you will only be able to remove positions from your school (the ones with the red Remove button). If you are a system editor and the user has staff assignments in another system, the same rule applies to your system.

  2. 2

    Remove all.

    • a

      Select staff positions to select all staff positions in your school/system.

    • b

      Select application access rules to select all app access rules in your school/system.

    • c

      Select Yes, remove to remove the selected options.

    Please note: If a user is not removed from app access rules and moves to another LEA/system, that user will continue to have access to your system's data.
